4. Cadastro e distribuição inteligente

Adicione atletas sem Excel. A distribuição automática alterna categorias por horário e evita dois atletas da mesma categoria no mesmo bloco, quando houver vagas. Não altera a ordem original dos inscritos dentro de cada categoria.

Os dados são armazenados somente neste navegador. Faça cópias de segurança em XML/CSV.

Segurança e recuperação · 2.5

Salvamento automático local de atletas, configurações, chegadas e etapas de ranking importadas. Uma cópia de segurança JSON é recomendada ao fim de cada sessão.

Verificando armazenamento...

O backup completo contém dados da competição e arquivos de ranking importados. Armazenamento do navegador não substitui um backup externo. Não limpe os dados do navegador antes de exportar.

Identidade visual

Design 2.4: fundo #FFFEFD, laranja #F36B0B, cinza-chumbo #30353B e tipografia Poppins (quando disponível). A logo Norte Prisma está incorporada ao pacote para uso offline.

Como usar

Abra o arquivo index.html no Chrome ou Edge, selecione a planilha e exporte. Não requer servidor nem internet. Para colocar na tela inicial do Android como PWA, é necessário hospedar via HTTPS; o arquivo HTML também pode ser usado localmente por um gerenciador de arquivos compatível.

O arquivo XML representa uma StartList. Não gera resultados ou rastreamento GPS. Confira os dados e valide o XML no esquema XSD da IOF antes do uso oficial.

5. Chegadas e classificação por categoria

Registro manual offline: um operador captura horários e identifica os atletas depois. No modo de dois operadores, a segunda pessoa pode identificar os atletas no mesmo dispositivo; sincronização entre dispositivos ainda não está disponível.

O botão captura o instante do toque, sem aguardar identificação. O número de peito é opcional e pode ser associado depois.

Registros de chegada

Tempo líquido = chegada − largada programada. O horário de chegada é o registro bruto do relógio; o tempo líquido é utilizado na classificação. Atletas sem peito associado permanecem pendentes.
